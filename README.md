# Weather App 🌤️

Aplicación del clima en tiempo real desarrollada con Vue.js. Detecta tu ubicación automáticamente y muestra datos meteorológicos completos con un diseño moderno tipo dashboard.

## Características

- 📍 **Geolocalización automática** al abrir la app
- 🔍 **Búsqueda de ciudades** con autocompletado en tiempo real
- 🌡️ **Datos completos**: temperatura, sensación térmica, humedad, viento
- 📅 **Pronóstico de 7 días** con condiciones e íconos
- ⏰ **Pronóstico por hora** (siguientes 12 horas)
- 🎨 **Diseño dashboard** con glassmorphism y degradado azul

## Tecnologías

- **Vue.js 2** — Framework frontend
- **Open-Meteo API** — Datos meteorológicos (gratuita, sin API key)
- **CSS3** — Glassmorphism, animaciones, responsive

## Instalación

```bash
yarn install
```

## Desarrollo

```bash
yarn serve
```

## Producción

```bash
yarn build
```
